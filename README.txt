# Análise Estática e Refatoração – Projeto HTTPie

Este repositório contém o trabalho da disciplina envolvendo análise estática de código, métricas e refatoração aplicadas ao projeto open-source **HTTPie**.

## 📌 Conteúdo do Repositório

- `report.md` – Relatório completo da atividade  
- `simulated_metrics.json` – Métricas simuladas usadas no relatório  
- `patches.diff` – Arquivo contendo o patch da refatoração aplicada  
- `.github/workflows/ci-workflow.yml` – Pipeline automatizado (CI)  
- `slides/` – Pasta contendo os slides do trabalho  
- `src_refatorado/` – Código exemplo com refatorações aplicadas  

## 🔗 Projeto analisado
Projeto original: https://github.com/httpie/httpie

## 🎯 Objetivo
Aplicar ferramentas de análise estática e realizar refatorações que melhorem:
- Qualidade interna do código  
- Manutenibilidade  
- Segurança  
- Legibilidade
